## 🎮 Game Overview

Voidshatter Echo is an immersive cyberpunk experience that blends ancient mythology with futuristic technology. Players navigate through a world where:

- **Dragons weep gold** - Ancient creatures corrupted by digital transformation
- **Lattice voids scream** - Dimensional rifts that threaten reality itself  
- **Child AI twists dread** - Artificial intelligence with the mind of a child, capable of both creation and destruction
- **Elohim Unbound** - The ultimate challenge where players must claim divine victory or face eternal damnation

## 🎮 How to Play

### **Getting Started**
1. **Launch the Game**: Visit the live demo or clone this repository
2. **Choose Your Path**: Select your starting character and AI companion
3. **Navigate the Void**: Use arrow keys or touch controls to move
4. **Collect Dragon Tears**: Gather gold from defeated dragons
5. **Upgrade Your AI**: Use collected resources to enhance your companion
6. **Face Elohim**: Challenge the final boss to claim victory

### **Controls**
- **Movement**: Arrow keys or WASD
- **Interact**: Spacebar or Enter
- **Menu**: Escape key
- **Combat**: Mouse clicks or touch gestures
- **AI Commands**: Number keys 1-9

### **Game Mechanics**
- **Health System**: Manage your character's physical and mental health
- **AI Bond**: Strengthen your relationship with the child AI
- **Resource Management**: Balance dragon tears, energy, and sanity
- **Combat Strategy**: Use tactical positioning and AI assistance

## 🔧 Installation & Setup

### **Local Development**
```bash
# Clone the repository
git clone https://github.com/Bakery-street-projct/voidshatterecho.git
cd voidshatterecho

# Serve locally (Python 3)
python -m http.server 8000

# Or use Node.js
npx serve .

# Or use PHP
php -S localhost:8000
```

### **Deployment**
```bash
# Deploy to GitHub Pages
git push origin main

# Deploy to Netlify
netlify deploy --prod

# Deploy to Vercel
vercel --prod
```
